# Serbian and Bulgarian comparators for Burmese → Ukrainian transcription

## Serbian

Dedicated Burmese-specific Serbian system: NOT_ESTABLISHED.

Serbian scholarship on foreign-name transcription is nevertheless a useful methodological comparator. A study of Japanese onomastics emphasizes pronunciation, established usage, avoidance of unusual target-language clusters, simplicity and consistency, and warns against blindly importing another language's transcription.

For this project, Serbian therefore contributes a principle:

foreign source pronunciation → Serbian/Ukrainian target phonology → target orthography

rather than:

foreign source → Russian transcription → target language.

It is methodology, not a Burmese mapping table.

## Bulgarian

Dedicated Burmese-specific Bulgarian system: NOT_ESTABLISHED.

The current review did not locate a primary Bulgarian rule set specifically codifying Burmese→Bulgarian practical transcription. Isolated Bulgarian spellings of Myanmar names are insufficient to construct one.

Bulgarian remains a comparator category so future evidence can be added without rewriting the architecture.

## Conclusion

Russian is the only one of the three Cyrillic traditions currently supported as a dedicated Burmese practical-transcription predecessor.

Serbian is valuable because it demonstrates how a target-language transcription system should be designed without importing another language's transcription blindly.

Bulgarian is currently a research gap, not a table to be filled by intuition.
