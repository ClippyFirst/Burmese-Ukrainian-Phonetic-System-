# Limitations

The current implementation is a research scaffold, not a complete lexical analyzer or surface-phonetic synthesizer.

IPA generation covers a conservative seed inventory and selected vowel signs. Full vowel combinations, coda derivation, tone realization, allophony and corpus-backed lexical validation remain to be implemented.

Ukrainian candidate ranking remains an adapter until a stable machine-readable interface to ClippyFirst/Ukrainian-Phonetic-Inventory is established.

No lexical lookup table is used as a substitute for a phonological model.
